# 물류가 모이는 곳

도로 화물교통량, 권역 간 화물 수송량, 우체국 배달량, 서울 자치구의 CJ 차량 활동을 지도와 표로 탐색하는 웹 프로그램입니다. 물류 집중 구간과 거점의 관계를 비교하고 지하물류체계의 연결 방향을 검토할 수 있습니다.

**[사이트 열기](https://hansol000808.github.io/logistics-flow/)**

## 주요 기능

- **여섯 가지 지도 보기:** 중소형 화물차, 대형 화물차, 도로 동시 비교, 우체국 배달량, 권역 간 화물 OD, 서울 CJ 차량 활동을 전환합니다.
- **도로 집중 구간과 거점:** 중소형 29개와 대형 12개 구간을 표시합니다. 중복 1개를 제외한 고유 구간은 40개이며 물류시설 20곳, 부산항과 인천항을 함께 확인할 수 있습니다.
- **전체 도로 분석표:** 531개 조사 구간의 양방향 합계와 1,062개 방향별 기록을 제공합니다. 구간명과 노선으로 검색하고 차종별 지표, 정렬 순서, 지도 표시 여부로 필터링합니다.
- **권역 간 OD:** 제주를 제외한 8권역의 8×8 출발·도착 행렬과 28개 권역 쌍의 양방향 수송량을 확인합니다. 권역 내 이동은 행렬에 포함하고 지도 선에서는 제외합니다.
- **우체국 배달량:** 8권역의 배달량을 원 면적으로 비교합니다.
- **서울 CJ 차량 활동:** 25개 자치구의 경유지 총건수를 단계구분도와 목록으로 표시합니다. 자치구별 기준월 확인과 기준월 필터를 제공합니다.
- **데이터 내려받기:** 도로 구간, 도로 방향별 기록, OD, CJ, 우체국 배달량, 시설의 CSV 6종을 제공합니다. 자료실에서는 분석 노트북과 지도 파일을 열 수 있습니다.

## 사용 방법

1. 지도 보기에서 분석 대상을 선택합니다.
2. 지도나 목록의 항목을 선택해 수치와 설명을 확인합니다. 도로 지도에서는 물류시설과 항만 표시를 켜거나 끌 수 있습니다.
3. 전체 도로 분석표에서 구간을 검색하고 지표를 바꾸어 비교합니다. 구간을 선택하면 방향별 기록이 표시되며, 지도 좌표가 있는 구간은 지도에서도 확인할 수 있습니다.
4. OD 행렬과 CJ 기준월을 함께 확인하고, 필요한 집계표를 CSV로 내려받습니다.

## 로컬 실행

저장소를 내려받은 뒤 루트 폴더에서 실행합니다. 빌드 과정이나 API 키는 필요하지 않습니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 엽니다. JSON을 읽으므로 HTTP 서버를 사용해야 합니다. 배경지도 타일에는 인터넷 연결이 필요하며 Leaflet 라이브러리는 저장소에 포함되어 있습니다.

## 기술과 구성

- 웹 화면과 데이터 탐색: HTML, CSS, Vanilla JavaScript
- 지도: Leaflet 1.9.4, OpenStreetMap
- 데이터 처리: Python, Pandas, NumPy, openpyxl
- 데이터 형식: JSON, GeoJSON, CSV(UTF-8 BOM)

```text
index.html / styles.css / app.js  화면, 지도, 검색 및 분석표
data/research.json               웹에서 읽는 분석 데이터
data/*.csv                      내려받기용 집계표
archive/                        분석 노트북, 지도 파일, 자료 목록
scripts/build_data.py           데이터 집계 및 검증
requirements.txt                데이터 처리용 Python 의존성
DATA_SOURCES.md                  출처, 단위, 처리 기준
THIRD_PARTY_NOTICES.md           외부 소프트웨어와 지도 이용조건
vendor/leaflet/                  지도 라이브러리와 라이선스
site-manifest.json              파일 크기와 SHA256 목록
```

GitHub Pages에서는 `main` 브랜치의 루트(`/`)를 배포합니다. 내부 파일은 상대경로로 연결하며 `.nojekyll`을 포함합니다.

## 데이터 출처와 해석 기준

| 자료 | 출처와 기준 | 단위 및 범위 |
|---|---|---|
| 도로 교통량 | [한국도로공사 수시교통량](https://data.ex.co.kr/portal/docu/docuList?datasetId=19), 2021년 | 차량 대수. 531개 구간, 1,062개 방향별 기록. 중소형 3~7종, 대형 8~12종 합계 |
| 권역 간 화물 OD | [국가물류통합정보센터 O·D별 수송실적](https://www.nlic.go.kr/nlic/frghtRoad0010.action), 원출처 국가교통DB, 2020년 | 톤/년. 17개 시도를 제주 제외 8권역으로 재집계 |
| 우체국 배달량 | [우체국물류지원단 총괄국별 배달물량](https://www.data.go.kr/data/15040740/fileData.do), `20210831` 파일의 2020년 행 | 개. 제주 제외 8권역 합계 178,446,950개 |
| 서울 CJ 차량 활동 | 서울특별시 빅데이터 캠퍼스, 서울시 자치구단위 CJ택배차량 운행량 월별 통계 | `경유지_총건수(VIA_CNT)`, 건. 25개 자치구, 2020-03~2021-06 사이의 15개 기준월 |
| 서울 자치구 경계 | [southkorea/seoul-maps의 KOSTAT 2013 자료](https://github.com/southkorea/seoul-maps/tree/master/kostat/2013) | 25개 자치구의 경계 |
| 물류시설과 항만 | 국가물류통합정보센터를 참고한 분석용 거점 목록과 좌표 | 물류시설 20곳, 부산항 및 인천항 2곳. 근사 좌표 |

- 도로 교통량은 수시조사의 `시간=계` 값으로, 연간 총량이나 연평균 일교통량이 아닙니다. 지도에 표시한 40개 구간은 고정 선택 집합이며 전체 531개 구간에서 자동 선정한 상위 40개가 아닙니다.
- CJ 자료는 자치구마다 기준월이 다릅니다. 동일 월의 자치구 순위나 입지 우선순위로 해석할 수 없으며 차량 경유지 건수는 택배 배송 건수와 다릅니다.
- 차량 대수, 톤/년, 배달 개수, 경유지 건수는 서로 다른 지표이므로 합산하지 않습니다. 자료의 기준연도와 경계 기준연도도 함께 확인해야 합니다.
- 지도 연결선과 거점 좌표는 실제 도로 선형, 배송 영역, 예정된 지하 노선을 나타내지 않습니다. 시설 목록은 전국 전체 시설이나 현재 운영 상태를 확인한 자료가 아닙니다.
- 지하물류 연결 방향은 탐색적 분석과 제안입니다. 실시간 물류 현황, 최적 노선, 지질·지하 시설물·공사비·사업성 검증 결과를 제공하지 않습니다.

파일별 출처, 원본 대조 범위, 집계 방식과 사용조건은 [DATA_SOURCES.md](DATA_SOURCES.md)를 확인하세요.

## 데이터 집계 실행

웹 실행에는 Python 패키지가 필요하지 않습니다. 집계 데이터를 갱신하려면 원천 데이터와 좌표·선택 구간이 담긴 노트북, 서울 경계가 포함된 지도 HTML을 별도로 준비합니다.

```sh
python -m venv .venv
# 가상환경을 활성화한 뒤 실행
python -m pip install -r requirements.txt
python scripts/build_data.py --help
```

```sh
python scripts/build_data.py --source-dir /path/to/source-files --notebook /path/to/notebook.ipynb --map-html /path/to/map.html --output /path/to/output/research.json
```

`--expected-od /path/to/df_final.xlsx`를 추가하면 OD 64개 값을 비교할 수 있습니다. 빌더는 노트북을 실행하지 않고 좌표, 선택 구간, 거점 정보를 읽어 집계하며 도로 차종·시간·방향 합계와 CJ 자치구·경계 대응을 확인합니다. 전체 입력 자료는 저장소에 포함되어 있지 않으므로 웹을 실행할 때는 제공된 JSON과 CSV를 사용합니다.
