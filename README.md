# 물류가 모이는 곳

**지하물류체계 구축을 위한 물동량 집중 구간 탐구** — 2022년 2학기 연구 아카이브

**[사이트 열기](https://hansol000808.github.io/logistics-flow/)** · 연구자 HAN JAEHYEOK

도로 화물교통량, 권역 간 화물 수송량, 우체국 배달량, 서울 자치구의 CJ 차량 활동을 살펴 지하물류체계 도입을 검토할 위치를 탐색한 연구입니다. 2026-10-14에 프로젝트 작성자의 자료 사용 확인을 반영해 초기 공개본에 빠졌던 분석과 연구 자료를 보완했습니다.

## 웹에서 확인할 수 있는 내용

- **도로 집중 구간:** 당시 선정한 중소형 29개·대형 12개 구간을 개별 또는 함께 표시합니다. 한 구간이 겹쳐 고유 구간은 40개입니다.
- **물류 거점:** 물류시설 20곳과 부산항·인천항을 도로 지도와 함께 확인합니다.
- **권역 간 OD:** 2020년 17개 시도 자료를 제주 제외 8권역으로 묶은 8×8 행렬과 28개 권역 쌍의 양방향 수송량입니다. 권역 내 이동은 행렬에 포함하고 지도 선에서는 제외합니다.
- **우체국 배달량:** 2020년 8권역의 배달실적입니다. 원 면적을 물량에 비례시켰습니다.
- **서울 CJ 차량 활동:** 25개 자치구의 경유지 총건수를 단계구분도와 목록으로 표시하며 각 구의 기준월도 제공합니다.
- **전체 도로 분석표:** 531개 조사 구간의 양방향 합계와 1,062개 방향별 기록을 검색·정렬하고 내려받을 수 있습니다.
- **연구 기록:** 출력·개인 경로를 정리한 노트북, 당시 네 지도의 고정 표현, 가설과 해석 과정을 제공합니다.

자료실에서 각 항목의 설명과 파일을 확인할 수 있습니다. 가공 데이터는 `data/`의 CSV로도 제공합니다.

## 자료를 읽는 기준

이 사이트는 **2022년 당시의 탐색 연구**입니다. 실시간 정보나 지하화 수요·최적 노선·공사 타당성의 검증 결과가 아닙니다. 지역별 관찰과 경부축·수도권 연결·서울 도심의 구상은 당시 연구자의 해석으로 소개합니다.

도로 교통량은 수시조사의 차량 대수, OD는 톤/년, 우체국은 배달물량 개수, CJ는 차량 경유지 건수입니다. 서로 다른 지표이므로 합산하지 않습니다. CJ의 25개 구는 **2020-03부터 2021-06 사이의 서로 다른 15개 기준월**을 갖습니다. 같은 달의 자치구 순위나 택배 배송 건수로 해석하지 않습니다.

선정 도로 40개는 원래 지도에 그려진 수동 선택 집합입니다. 전체 531개 구간의 양방향 합계에서 자동 선정한 상위 40개가 아닙니다. 전체 표는 별도로 제공하며 좌표가 없는 구간의 위치는 추정하지 않습니다. 지도 직선과 거점 위치는 당시 입력한 근사 좌표로 실제 도로 선형·배송 영역·터널 경로가 아닙니다.

## 로컬 실행

빌드 과정이나 API 키가 필요하지 않습니다. 저장소 루트에서 실행합니다.

```sh
python -m http.server 8000
```

`http://localhost:8000/`을 엽니다. JSON을 읽으므로 HTTP 서버를 사용합니다. 배경지도 타일을 불러올 때 인터넷 연결이 필요하며, 지도 라이브러리는 저장소에 포함합니다.

## 데이터 재구성

원본 자료를 가진 사용자는 집계를 재생성할 수 있습니다. 원본 개발 폴더 전체는 저장소에 넣지 않습니다.

```sh
python -m venv .venv
# 환경을 활성화한 뒤
python -m pip install -r requirements.txt
python scripts/build_data.py --help
```

```sh
python scripts/build_data.py --source-dir /path/to/source-files --notebook /path/to/original-notebook.ipynb --map-html /path/to/df_map1.html --expected-od /path/to/df_final.xlsx --output /path/to/output/research.json
```

정확한 입력 옵션은 `--help`를 확인하세요. 빌더는 원본 노트북을 실행하지 않고 좌표·선 선택·거점 표시를 읽으며 지역과 구간 이름으로 집계합니다. 저장된 OD 64개 값, 도로 차종·시간·방향 합계, CJ 25개 구와 경계 대응을 검증합니다. 새 자료의 사용 가능 여부는 스크립트가 판단하지 않습니다.

자료실 노트북은 2022년 코드 기록입니다. 과거 Folium API와 수동 시각화가 포함되며 현행 재구성에는 `scripts/build_data.py`를 사용합니다.
