이 자료실은 물류 데이터의 분석 코드와 지도 자료를 제공합니다.
관찰과 해석을 확인하는 자료이며 수요 예측·정확한 운송 경로·건설 타당성을
입증하지 않습니다.

research-notebook.ipynb
- 데이터 처리와 지도 표현 코드, 수동 입력 상수가 포함되어 있습니다.
  저장 출력과 실행 횟수는 비어 있으며 입력 경로는 ../data-source/입니다.
- 해당 폴더의 같은 이름 원자료와 코드에 맞는 라이브러리 환경이 필요합니다.
  집계 JSON만으로 전체 실행되지 않으며 전체 실행 검증이 완료된 파이프라인은 아닙니다.
- 지도3의 시설 마커 코드는 주석 처리되어 있습니다.

original-map-1.html / original-map-2.html /
original-map-3-1.html / original-map-3-2.html
- 25개 자치구, OD 연결선 28개와 배달량 원 8개,
  도로 선과 물류시설 20곳·항만 2곳을 표시합니다.
- 도로 지도마다 선 객체 41개가 있습니다. 서로 다른 크기 분류에서 겹치는 구간을
  포함하므로 도로의 고유 구간 수 40개와 다릅니다.
- 선의 좌표·두께, 원의 좌표·반지름, 시설·항만의 좌표·색 구분은 지도 코드에 정의됩니다.
- 배경지도는 OpenStreetMap 표준 타일이며 저장소에 포함된 Leaflet을 사용합니다.
  정보 마커와 범례는 지도 HTML 안에 구현되어 있으며 외부 CDN에 의존하지 않습니다.
- 자료실 지도는 배달량에 비례하는 원 반지름을, 인터랙티브 지도는 비례하는 원 면적을
  사용합니다. CJ 자료는 구별 기준월이 다르고, 도로와 OD의 선은 근사 직선이므로
  같은 시점의 수요 비교나 실제 경로로 해석하면 안 됩니다.
- 물류시설·항만 목록의 기준연도는 2022년입니다.
- 배경지도는 외부 타일 서비스의 표시값이며 분석 자료와 기준시점이 같다는 뜻이 아닙니다.

제3자 도판·지도·데이터의 권리는 각 원권리자에게 있습니다.
사이트 코드의 라이선스가 이 원문 자료 전체에 적용된다고 간주하지 마세요.
